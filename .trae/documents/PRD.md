# 田忌赛马 - 产品需求文档 (PRD)

## 1. 项目概述

### 项目名称
田忌赛马

### 项目类型
网页策略养成游戏

### 核心玩法
玩家通过购买和组装马匹部件来培养自己的赛马，然后在赛场与系统马进行三局两胜的赛马对决，赢取金币或面临金币损失。

### 目标用户
- 喜欢休闲养成类游戏的玩家
- 喜欢策略对决类游戏的玩家
- 喜欢收集和组合系统的玩家

### 参考游戏
Horsey Game - 孟菲斯风格 + 像素艺术风格

---

## 2. 游戏流程

### 2.1 主界面
- 显示玩家当前金币数量
- 三个主要入口按钮：养马屋、商店、赛场

### 2.2 养马屋 (Horse Barn)
- 玩家组装自己马匹的地方
- 最多同时拥有3匹马
- 点击"新拼一匹马"进入拼马界面
- 每匹马由多个部位组成，需要从商店购买

### 2.3 商店 (Shop)
- 购买马匹部位
- 部位类型：
  - **头部** (Head)
  - **身体** (Body)
  - **腿部** (Legs)
  - **尾巴** (Tail)
  - **鬃毛** (Mane)
- 品质等级：
  - 普通 (Common) - 白色
  - 稀有 (Rare) - 蓝色
  - 史诗 (Epic) - 紫色
  - 传说 (Legendary) - 金色
- 属性加成：速度、加速、耐力、魔法
- 价格从50-500金币不等

### 2.4 赛场 (Race Track)
- 与系统马进行比赛
- 三局两胜制
- 每次比赛需要支付入场费（50金币）
- 胜利奖励：150金币
- 失败惩罚：扣除入场费
- 可以选择自己的任意一匹马参赛

## 3. 游戏机制

### 3.1 经济系统
- **初始金币**：300
- **入场费**：50金币/场
- **胜利奖励**：150金币
- **失败惩罚**：失去入场费
- **卖马价格**：部件总价的70%

### 3.2 马匹属性
每匹马有4个核心属性：
1. **速度 (Speed)** - 最高速度上限
2. **加速 (Acceleration)** - 起步和提速能力
3. **耐力 (Stamina)** - 长时间维持高速的能力
4. **魔法 (Magic)** - 特殊效果触发率

### 3.3 部位属性加成
- **普通部位**：+5-10属性
- **稀有部位**：+15-25属性
- **史诗部位**：+30-45属性
- **传说部位**：+50-70属性

### 3.4 比赛判定
- 系统根据马匹的综合属性计算得分
- 速度 × 0.3 + 加速 × 0.3 + 耐力 × 0.25 + 魔法 × 0.15
- 添加随机波动（±10%）模拟比赛不确定性
- 三局两胜决定最终胜负

## 4. 视觉设计

### 4.1 风格定位
- **主风格**：孟菲斯风格 (Memphis Style)
  - 大色块
  - 几何形状
  - 对比色彩
  - 动态活泼

- **辅风格**：像素艺术 (Pixel Art)
  - 马匹以像素风格呈现
  - 8-bit 复古感
  - 清晰的像素边缘

### 4.2 色彩系统
```
主色调：
- 珊瑚红 (Coral Red): #FF6B6B
- 明黄色 (Bright Yellow): #FFE66D
- 天蓝色 (Sky Blue): #4ECDC4
- 紫罗兰 (Violet): #9B59B6
- 深粉色 (Deep Pink): #E91E63

辅助色：
- 米白色 (Off White): #F8F9FA
- 深灰色 (Charcoal): #2C3E50
- 纯黑 (Pure Black): #000000

背景色：
- 深蓝 (Dark Blue): #1A1A2E
- 深紫 (Dark Purple): #16213E
```

### 4.3 字体选择
- 标题字体： Bold Geometric Display Font (如：Bungee, Black Ops One)
- 正文字体： Monospace Pixel Font (如：Press Start 2P, VT323)
- 中文字体：思源黑体 (Noto Sans SC)

### 4.4 UI 组件设计
- **按钮**：大圆角矩形，带阴影和边框
- **卡片**：带装饰性几何图案的背景
- **图标**：简洁的像素风图标
- **动画**：弹性动画、摇晃效果、闪烁

## 5. 界面结构

### 5.1 页面层级
```
1. 主界面 (Main Menu)
   - 金币显示
   - 养马屋入口
   - 商店入口
   - 赛场入口

2. 养马屋界面 (Horse Barn)
   - 马厩展示区（3个槽位）
   - 新拼马按钮
   - 卖马按钮

3. 拼马界面 (Horse Builder)
   - 5个部位插槽（头、身、腿、尾、鬃）
   - 商店购买入口
   - 保存马按钮

4. 商店界面 (Shop)
   - 商品展示区
   - 分类筛选
   - 购买按钮
   - 库存显示

5. 赛场界面 (Race Track)
   - 赛道视图
   - 玩家马 vs 系统马
   - 比分显示
   - 开始比赛按钮
   - 比赛结果弹窗

6. 比赛动画界面 (Race Animation)
   - 像素风格赛马动画
   - 实时位置更新
   - 冲刺特效
```

## 6. 交互设计

### 6.1 主要交互
- **点击**：选择、确认购买、进入界面
- **拖拽**：组装马匹部位（从库存拖到插槽）
- **长按**：查看物品详情
- **滑动**：浏览商品列表

### 6.2 反馈系统
- **成功**：绿色闪烁 + 音效
- **失败**：红色抖动 + 警告音效
- **获得物品**：弹跳动画 + 金币飞散效果
- **失去物品**：淡出 + 碎片效果

## 9. 技术实现

### 9.1 技术栈
- **前端**：纯 HTML5 + CSS3 + JavaScript
- **无框架依赖**：轻量级、快速加载
- **Canvas**：用于比赛动画渲染
- **LocalStorage**：存档数据持久化

### 9.2 文件结构
```
tianji-horse/
├── index.html          # 主页面
├── style.css          # 样式文件
├── game.js            # 游戏逻辑
├── assets/            # 资源文件夹
│   ├── fonts/         # 字体文件
│   └── images/        # 图片资源
└── README.md          # 说明文档
```

### 9.3 响应式设计
- 移动优先设计
- 适配手机和平板
- 横屏和竖屏支持
- 触摸友好的按钮尺寸（最小48px）
