# 田忌赛马

一款基于 Horsey Game 风格的网页策略养成游戏，玩家通过购买和组装马匹部件来培养赛马，与系统进行三局两胜的赛马对决。

## 🎮 游戏玩法

### 游戏流程

1. **养马屋** - 在这里组装你的马匹
   - 点击"新拼一匹马"开始组装
   - 为马匹命名
   - 从商店购买或使用背包中的部件
   - 保存马匹到马厩

2. **商店** - 购买马匹部件
   - 5种部件类型：头部、身体、腿部、尾巴、鬃毛
   - 4种品质等级：普通、稀有、史诗、传说
   - 不同品质提供不同的属性加成
   - 可按类型和品质筛选商品

3. **赛场** - 与对手进行赛马比赛
   - 选择你的一匹马参赛
   - 支付50金币入场费
   - 三局两胜制
   - 胜利获得150金币奖励
   - 失败损失入场费

### 马匹属性

每匹马有4个核心属性：
- **速度** - 最高速度上限
- **加速** - 起步和提速能力
- **耐力** - 长时间维持高速的能力
- **魔法** - 特殊效果触发率

综合评分计算公式：
```
总分 = 速度×0.3 + 加速×0.3 + 耐力×0.25 + 魔法×0.15
```

## 🚀 启动游戏

直接在浏览器中打开 `index.html` 文件即可开始游戏。

### 本地服务器方式

如果你想通过本地服务器运行：

```bash
# Python 3
python -m http.server 8000

# Node.js
npx serve .
```

然后在浏览器中访问 `http://localhost:8000`
